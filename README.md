# Sewing Hobby Website

A beginner sewing website created by Jessica Longoria. The site introduces essential supplies, practical tips, and a simple fabric bookmark project. It also gives me a chance to practice HTML, CSS, Markdown, and project planning.

## Project links

- [Live website](https://Lon67085.github.io/My-Sewing-Hobby/)
- [Project documentation](docs/)
- [Project scope](docs/scope.md)
- [Project plan and risk analysis](docs/plan.md)
- [Project retrospective](docs/retrospective.md)


## Website features

- A homepage with beginner supplies, tips, and a first project.
- An About page explaining the website’s purpose.
- One shared external stylesheet with purple and white styling.
- A simple single-column layout, keyboard focus indicators, and a skip link.
- Beginner-friendly code with indented HTML and short, commented CSS rules.
